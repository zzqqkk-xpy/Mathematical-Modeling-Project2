# 灾后应急救援协同路径与调度优化

> 基于最短路径算法、时序仿真、自适应模拟退火与多源信息融合的灾后应急救援调度研究项目。

## 1. 项目简介

灾害发生后，道路通行能力下降、受灾点需求差异明显、救援资源分布有限，如何合理分配救援队伍、规划救援路线并安排物资补给，是提高应急救援效率的重要问题。

本项目基于数学建模论文《灾后应急救援问题》及对应 Python 程序，研究灾后道路网络中多支救援队伍的任务分配、协同救援、物资补给与不确定路况下的鲁棒调度问题。

项目以道路网络为基础，将救援队、受灾点和应急物资站映射为路网节点，利用最短路径算法计算通行时间，并通过时序仿真与启发式优化方法生成救援调度方案。

项目研究场景包含 **8 支救援队、20 个受灾点和 5 个应急物资站**，按照论文中的三个问题逐步展开，从基础协同救援调度扩展到考虑物资约束的补给调度，最后研究动态道路扰动下的鲁棒调度。

**项目关键词：**

灾后应急救援、数学建模、车辆路径问题（VRP）、多队伍协同调度、模拟退火算法、Dijkstra、多源信息融合、鲁棒优化、蒙特卡洛仿真。

## 2. 研究问题与解决方案

### 问题一：基础协同救援调度

在道路正常通行且不考虑车载物资约束的条件下，综合考虑救援队能力、受灾点需求、灾情等级及任务先后顺序，优化多支救援队伍的协同救援路线与时序。

主要方法：

1. 将道路网络抽象为加权图；
2. 使用 NetworkX 的 Dijkstra 最短路径算法计算节点间最短通行时间；
3. 根据救援队能力与受灾点需求生成可行协同队伍组合；
4. 建立事件驱动的时序仿真器，模拟队伍行驶、协同等待和现场作业过程；
5. 使用自适应模拟退火算法搜索任务分配及访问顺序；
6. 通过总完工时间、灾情加权响应时间、行驶时间和等待时间等指标评价方案。

**论文给出的主要结果：**

* 总完工时间：491.2 分钟；
* 加权平均响应时间：191.8 分钟。

### 问题二：考虑物资消耗与中途补给的协同调度

在问题一的基础上，进一步考虑救援过程中车载物资的动态消耗、物资站库存容量、补给服务时间及补给路线选择，制定满足受灾点需求的补给调度方案。

主要考虑：

* 救援队车载物资的动态消耗；
* 应急物资站的库存与补给能力；
* 救援队中途补给的路线选择；
* 补给服务时间对整体救援时序的影响；
* 受灾点物资需求满足情况。

程序根据路线配置模拟队伍行驶、补给、协同等待及救援作业过程，并生成路线拓扑图、协同甘特图、物资库存与物资站负荷等可视化结果。

**代码实现说明：** `src/question2.py` 中的路线方案以程序内配置的路线序列为基础进行仿真和评价；与问题一、问题三的搜索优化代码不同，它不是独立运行的模拟退火求解器。

**论文给出的主要结果：**

* 总完工时间：587.6 分钟；
* 受灾点物资满足率：100%。

### 问题三：多源信息融合与动态道路扰动下的鲁棒调度

针对灾后道路状态存在不确定性、现场调查信息来源多样且报告时间不同等情况，融合无人机巡查、前线救援人员和现场报告等多源道路调查信息，将道路阻断、拥堵和缓行等描述转化为路段通行时间修正，并在动态路网下进行鲁棒调度与随机扰动评估。

主要方法：

1. 根据调查信息来源设置权重，并结合报告时间进行时效衰减；
2. 通过道路状态关键词识别阻断、延误和正常通行信息，形成路段状态及通行时间修正；
3. 基于修正后的路网重新计算最短路径；
4. 使用时空协同仿真评价候选方案，并通过自适应模拟退火搜索队伍任务序列及补给安排；
5. 通过随机路况扰动与蒙特卡洛仿真评估方案的鲁棒性。

**论文给出的主要结果：**

* 典型仿真总完工时间：2416.1 分钟；
* 蒙特卡洛仿真次数：1000 次；
* 随机路况仿真平均完工时间：2433.2 分钟；
* 随机路况仿真完工时间 95% 分位数：2902.3 分钟。

## 8. 运行方法

建议使用 Python 3.10 或以上版本创建独立虚拟环境，并在安装依赖后运行。



三个程序分别对应三个建模问题，可根据需要独立运行。

## 10. 项目特点与工作亮点

1. **问题逐层递进：** 从基础协同救援调度扩展到物资约束下的补给调度，再进一步考虑动态道路扰动与不确定信息。
2. **多队伍协同调度：** 综合考虑救援队伍能力、受灾点需求及任务先后关系，研究多支救援队伍的任务分配与协同作业。
3. **路径规划与时序仿真结合：** 利用 Dijkstra 算法计算道路最短通行路径，并通过时序仿真评价救援队伍的行驶、等待和作业过程。
4. **启发式优化求解：** 在问题一和问题三中使用自适应模拟退火算法搜索调度方案。
5. **多源信息融合：** 将不同来源、不同时间的道路调查信息进行加权融合，支持动态道路状态更新。
6. **鲁棒性分析：** 通过随机道路扰动和蒙特卡洛仿真，分析不确定路况下调度方案的表现。
